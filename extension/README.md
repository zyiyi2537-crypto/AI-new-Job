# JobPilot CN Chrome 采集助手

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本目录：`D:\toudi\extension`。
4. 保持 JobPilot CN 本地服务运行。
5. 在 BOSS 直聘、智联招聘、猎聘、拉勾或其他招聘网站打开搜索结果/岗位详情页。
6. 点击浏览器工具栏中的 JobPilot CN 图标，选择“采集当前岗位”或“扫描当前列表”。

扩展只读取当前标签页中已经显示给用户的岗位信息，并发送到本机 `http://127.0.0.1:8787`。它不读取或导出 Cookie、密码和浏览记录，也不执行自动投递。
